# Changes sidebar scope

[Light](light.png) and [dark](dark.png) captures of the real `RightPanel`,
`ChangesPanel`, and `RepoPanel` components at a 400 × 580 CSS-pixel viewport.
A temporary browser harness supplied an empty turn diff and a workspace diff
containing a modified file and an untracked file. No personal data is present.

The captures show the turn-specific empty state and the persistent shortcut to
Repo → Uncommitted. Clicking the shortcut was also verified in the browser:
both workspace files appeared. The temporary harness was removed after capture.
